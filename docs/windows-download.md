# Windows 版下载、校验与安全提示

[English](windows-download.en.md) | 中文

本页可直接复制到 GitHub 发布说明。下文 `<版本>` 换成实际版本号，例如 `0.4.0`。

## 选哪个文件

| 文件 | 适合 | 用法 |
| --- | --- | --- |
| `BaoZhang-Desktop-<版本>.zip`（**推荐**） | 所有用户，免安装 | 右键 →“全部解压缩”到普通文件夹（如“文档\随手报账”），运行其中的 `随手报账.exe`。保留同目录其他文件，不要只复制 EXE，也不要在 ZIP 里直接双击运行。 |
| `BaoZhang-Desktop-Setup-<版本>.exe` | 想要开始菜单和桌面快捷方式 | 双击安装，只装到当前用户，不需要管理员权限，可选安装目录。卸载在“设置 → 应用”里，卸载不会删除票据数据。 |

两种方式的票据数据都保存在 `%APPDATA%` 下的“随手报账”文件夹，与旧版便携 EXE 是同一位置，换用哪种方式都不会丢数据。升级前建议先在左下角导出备份 ZIP，并关闭正在运行的旧版。

Windows 0.3.1 及更早的发布页只有便携版 `BaoZhang-Desktop-<版本>.exe` 和 ZIP，请下载 ZIP。便携版每次启动都要先把约 600 MB、7000 多个文件静默解压到临时目录，期间没有任何窗口，容易被误以为“打不开”，也更容易被安全软件拦截，所以从 0.4.0 起不再提供。

## 校验文件（SHA-256）

发布页附有每个文件的 SHA-256。下载后在文件所在文件夹按住 Shift 右键 →“在终端中打开”，运行（文件名换成实际下载的文件）：

```powershell
Get-FileHash .\BaoZhang-Desktop-<版本>.zip -Algorithm SHA256
```

输出的 Hash 与发布页一致（不区分大小写）才说明文件完整、未被改动；不一致请删除后重新下载。只从本项目的 GitHub 发布页下载。

## 遇到 Windows 安全提示时

随手报账没有受信任的代码签名证书，Windows 会把它当作“未知发布者”，新版本刚发布时下载量少，还没有信誉。这类提示是**信誉提示**，不是检测到病毒：

| 提示 | 含义 | 做法 |
| --- | --- | --- |
| Edge：“通常不会下载 xxx”/“无法验证此文件”；Chrome：“不常被下载” | 浏览器下载信誉检查（Microsoft Defender SmartScreen 或 Google 安全浏览）对未签名、下载量少的 EXE 的提示 | 先确认来自本项目发布页。Edge 点“…”→“保留”→“显示更多”→“仍然保留”；Chrome 在下载列表里选“保留”。或改下载 ZIP（ZIP 一般不会被这样拦）。保留后先核对 SHA-256。 |
| 运行时蓝色窗口“Windows 已保护你的电脑” | SmartScreen 应用信誉检查，原因是“未知发布者” | 核对 SHA-256 一致后，点“更多信息”→“仍要运行”。 |
| Windows 安全中心 / Defender 通知“发现威胁”“病毒”并隔离文件 | 杀毒引擎判定（可能是误报） | **不要**恢复文件、关闭防护或添加排除项。记下通知里的威胁名称，连同文件名和 SHA-256 反馈给作者；作者确认后可把该文件提交 Microsoft 误报复核。期间可改用另一个下载文件。 |

不要为了运行本软件关闭杀毒软件、实时保护或 SmartScreen，也不要添加排除项。
