# 随手报账 · 用户手册

[English](user-guide.en.md) | 中文

适用版本：Android 0.3.0 / Windows 0.4.0。手机和电脑各自保存数据，互不同步。

## 1. 下载与安装

从 [GitHub 发布页](https://github.com/Asherdeng138/ExpenseClaims/releases/latest) 下载（无需登录）。发布页附有每个文件的 SHA-256，可用来确认文件完整。

### Android（8.0 及以上）

1. 下载 `BaoZhang-<版本>.apk`。浏览器如果提示这类文件可能有害，确认来自本项目发布页后选择继续下载。
2. 打开 APK。第一次安装时 Android 会要求允许浏览器或文件管理器“安装未知应用”，这是系统对所有非应用商店安装包的要求，按提示允许即可。
3. **从旧版升级时直接覆盖安装，不要先卸载**，卸载会清空手机里的发票。新版与旧版使用同一签名，覆盖安装会保留数据。如果系统提示必须先卸载，请停止并反馈。
4. 如果 Google Play 保护机制提示这是未经它扫描的应用，可以按提示继续安装（通常在“详情/更多”里）。本应用不申请联网、短信、通讯录等权限，票据只在本机处理。如果提示“已拦截有害应用”，请不要强行安装，把截图反馈给作者。

### Windows 10/11（64 位）

| 文件 | 用法 |
| --- | --- |
| `BaoZhang-Desktop-<版本>.zip`（推荐） | 右键 →“全部解压缩”到普通文件夹，运行其中的 `随手报账.exe`。不要只复制 EXE，也不要在 ZIP 里直接运行。 |
| `BaoZhang-Desktop-Setup-<版本>.exe` | 安装版，只装到当前用户，不需要管理员权限，带开始菜单和桌面快捷方式。 |

软件没有购买商业代码签名证书，所以 Windows 会显示“未知发布者”。核对 SHA-256 后：浏览器提示“不常下载”时选择“保留”；运行时出现“Windows 已保护你的电脑”时点“更多信息 → 仍要运行”。如果 Windows 安全中心报告“发现威胁”，不要恢复文件，也不要关闭杀毒软件，请把威胁名称反馈给作者。详见 [Windows 下载与校验](windows-download.md)。

升级时先关闭旧版，再运行新版。ZIP 版、安装版和旧便携版共用同一个数据目录（`%APPDATA%\baozhang-desktop`），换用哪种都不会丢数据。

## 2. 第一次使用：语言和货币

- **手机**：点右上角的设置按钮（“设置与说明”）。**电脑**：点左下角“设置”。
- 语言可选中文或英文（英式英语）；货币可选英镑 GBP 或欧元 EUR。选择会保存，重启后保留。
- 每张发票记录自己的货币，软件**不做汇率换算**。切换货币不会改动已保存的发票；编辑时也可以单独修改某张发票的货币。合计按币种分开显示，如 `£10.00 + €5.00`。
- 切换语言不改数据。导出的文件名、Excel 表头和费用类别跟随当前语言。

## 3. 五类费用

市内交通（地铁）、市外交通、出差餐补、办公用品、客户招待。添加发票前先选择类别。

## 4. 添加和核对发票

### 手机

1. 在首页点“添加发票”，先选费用类别。
2. 选“拍照扫描”，或“批量导入图片 / PDF”（可长按多选，每批最多 30 个文件）。每个文件是一张发票；多页发票可以在核对时点“追加拍照”或“追加附件”。
3. 软件在本机自动裁剪、矫正并识别，约 10–30 秒。裁剪不准时点“裁剪 / 矫正”拖动四个角。原图始终保留。
4. 核对日期、实付金额、商家。识别出的候选值显示为按钮，点一下即可填入；没把握的字段会留空，需要手动填写。所在地和备注可选填。
5. 勾选“我已核对日期、实付金额、商家和费用分类。”，点“确认并保存”。批量导入时会自动进入下一张，关闭后可以继续未完成的批次。

### 电脑

1. 在“发票工作台”点“＋ 批量添加发票”，或把文件拖到窗口任意位置（每批最多 100 个，单个文件最多 50 MB）。微信图片可以复制后点“粘贴微信图片”。选好费用类别后导入。
2. 勾选要识别的发票，点“识别选中”。识别按顺序进行，可随时“停止后续识别”。
3. 对照右侧原件核对（“查看大图”可在独立窗口放大、旋转、翻页），勾选“我已对照原件核对日期、金额、商家与种类”，点“保存并查看下一张”。没核对完可以先“保存待核对”。

**只有勾选核对并保存的发票才能导出。** 识别结果只是候选值，不会自动确认。

## 5. 日历与出差国家

- 日历用颜色标记每天的状态：**绿色出差、红色办公、蓝色休假**，同时显示文字。日历状态与发票类别相互独立。
- 手机点“标记出差 / 办公 / 休假”，电脑在“票据日历”右侧标记。可以标记一天或一段日期。
- 标记“出差”时选择**出差国家**和**天数**（天数和结束日期联动）。默认英国。

| 每日餐补标准 | 国家 |
| --- | --- |
| £50（英镑） | 英国 |
| €60 | 瑞士、芬兰、瑞典、丹麦、挪威、冰岛 |
| €50 | 荷兰、比利时、卢森堡、德国、法国、奥地利、爱尔兰、以色列等中东国家 |
| €40 | 波兰、意大利、希腊、西班牙、葡萄牙、捷克、斯洛伐克、匈牙利、塞尔维亚、罗马尼亚、保加利亚、俄罗斯、南非、克罗地亚等其他东欧国家 |

- 发票日期落在出差日时，货币会自动改为该国货币，可以手动改回。
- 瑞士、北欧、东欧等地的标准按公司规定以欧元计算；当地货币（如 CHF、PLN）的发票暂不支持。

## 6. 额度提醒（只提示，不阻止保存或导出）

- **出差餐补**：额度 = 出差国家每日标准 × 连续出差天数，单日可以超出。换国家、办公、休假或未标记的日期会把出差分成新的一段；跨月、跨年不会中断。只统计与该国货币相同、已确认的餐补发票，其他货币只提示数量。
- **市内交通**：每个自然月 £150，只统计英镑发票；设置为欧元时不显示。
- 低于额度时提示还有多少未使用，等于额度显示已用满，超过显示超额。

## 7. 导出报账

1. 手机点底部“导出”，电脑点“报账导出”。
2. 先选一个费用类别，再选日期范围（包含开始和结束当天），然后勾选要导出的发票。
3. 点“生成 PDF + Excel”。得到一份合并的发票 PDF 和一份 Excel 明细汇总。Excel 不含所在地列，每行标明货币，每种货币单独合计；页码与 PDF 对应。
4. 手机可“保存到手机文件夹”或“分享文件”；电脑可“打开导出文件夹”。
5. 文件名示例：`2026-10-01至2026-10-31_出差餐补报账_发票合集.pdf`；市内交通按月份命名，如 `2026年10月_市内交通报账_明细汇总.xlsx`。英文界面如 `2026-10-01_to_2026-10-31_Travel_Subsistence_Receipts.pdf`。

## 8. 归档与回收站

- 导出成功后可以选择“归档”本次导出的发票。归档的发票仍在日常列表和额度统计里，也可以再次导出，或“取消归档”。
- 在“归档与回收站”里删除归档发票会移入回收站，30 天内可“恢复到归档区”，到期后自动清理。其他地方的删除是永久删除。

## 9. 升级、换设备与备份

### 电脑升级到新版本（同一台电脑）：不用同步，旧发票自动还在

电脑版的发票不放在程序文件夹里，而是放在当前 Windows 用户的数据文件夹 `%APPDATA%\baozhang-desktop`（里面有 `receipts.json` 和 `documents` 原件文件夹）。旧便携版、ZIP 版和安装版都读这同一个文件夹，所以：

1. 建议先在旧版左下角点“备份全部票据”，留一份 ZIP 以防万一。
2. 关闭正在运行的旧版。
3. 解压新版 ZIP 运行 `随手报账.exe`，或运行 `Setup` 安装版。
4. 打开后以前的发票、日历标记和设置都会显示出来。

确认新版正常后，旧的程序文件（如旧便携版 EXE、旧 ZIP 解压的文件夹）可以删除；**不要删除 `%APPDATA%\baozhang-desktop`**，那里是你的发票。想查看这个文件夹，可按 Win + R，粘贴 `%APPDATA%\baozhang-desktop` 后回车。卸载安装版也不会删除它。

### 手机升级到新版本：直接覆盖安装

直接安装新 APK 覆盖旧版，发票、草稿和日历自动保留。**不要先卸载旧版**，卸载会删除手机里的发票。

### 换一台电脑

1. 在旧电脑左下角点“备份全部票据”，保存得到的 ZIP。
2. 把 ZIP 拷到新电脑，安装或解压新版并打开。
3. 点左下角“恢复电脑版备份”，选择这个 ZIP。恢复是合并进来的：重复的原件会跳过，不覆盖新电脑上已有的日历标记和设置；每张发票保留自己的货币。

如果备份超过 250 MB，程序会提示“请直接复制应用数据文件夹”。这时在**两台电脑都关闭随手报账**后，把旧电脑的整个 `%APPDATA%\baozhang-desktop` 文件夹复制到新电脑的同一位置。只在新电脑上还没有发票时这样做，否则会覆盖新电脑上的数据。

### 换手机

在旧手机设置里点“导出全部原件备份（ZIP）”，把 ZIP 存到电脑或网盘。手机版**暂时没有一键恢复**：ZIP 里保留了全部原件、明细和日历，换新手机后需要用“批量导入图片 / PDF”重新导入原件并核对。

### 手机和电脑之间

手机和电脑**不会互相同步**，两边各自保存自己的发票。手机的备份不能导入电脑版，电脑的备份也不能导入手机。需要在两边都用的发票，请分别添加。

### 备份提醒

- 备份包含原件、发票明细（含每张发票的货币）和日历；恢复时不会改动本机的语言和货币设置。
- **卸载手机应用或清除应用数据会删除发票**；重装系统或换电脑前也请先备份。

## 10. 隐私与限制

- 无账号、无服务器、无云同步；识别在本机离线完成。手机应用没有联网权限，电脑版拦截所有网络请求。
- 识别必须人工核对。在约 150 张真实票据的测试中，日期、金额、商家三项全对约 61%。
- 不支持零金额、退款，也不支持英镑和欧元以外的货币；欧洲语言的月份名日期（如 `12. März 2026`）需手动填写。
- 手机：单附件 50 MB，一张发票最多 30 个附件，单个 PDF 最多 200 页，一次导出最多 200 页。电脑：单文件 50 MB，每批最多 100 个文件，一次导出最多 300 页，备份最多 250 MB。
